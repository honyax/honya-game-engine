1つ目は「放射照度は滑らかなので、9個で足りる」。放射照度は、入ってくる光に余弦のこぶ(N・L)を掛けて半球で積分したもの。余弦のこぶはとても滑らかなので、球面調和(SH)の次数ごとに見ると高い次数ほどほとんど残らない(要点1)。2次(9個)で打ち切っても、「上半分だけ光る空」なら誤差 0.02% で再現できる。縮める手順は、次数ごとに掛け算するだけ。

理論の要点

1. 放射照度は「余弦のこぶで均した光」なので、9個で足りる

ある点のある向きの面が受ける光(放射照度)は、半球から来る光に N・L を掛けて足したもの。

  E(n) = ∫ L(ω) max(0, n・ω) dω      (半球の積分。Day 36 の irradiance.frag が画素ごとにやっていたこと)

L(ω)(どの向きからどれだけ来るか)は細かい模様を持ちうるが、max(0, n・ω)(余弦のこぶ)はとても滑らかなので、掛けて積分すると模様の細かい成分はほとんど消える。球面調和(SH)は球の上のフーリエ級数で、次数 l が上がるほど細かい模様を表す。余弦のこぶと畳み込むと、次数ごとに決まった割合しか残らない。

次数 l係数の数残る割合 Â_l / π何を表すか
011向きによらない平均
132/3どちらから多く来るか(x・y・z の傾き)
251/4上下から来て横からは来ない、のような偏り
370ちょうど消える(3 以上の奇数次はすべて 0)
49−1/24ほぼ消える

だから2次まで(1 + 3 + 5 = 9 個)で打ち切っても、放射照度はほとんど変わらない。自己チェックの「上半分だけ光る空」は、0次と奇数次しか持たない関数なので、3次以上がちょうど消えて9個で厳密に再現できる(上 1.0002 / 横 0.5000 / 下 −0.0002)。

9個 x RGB = 27 個の数。同じものを Day 36 の放射照度マップ(32x32 x 6面 x RGB)で持つと 18,432 個になる。今日はそれを 448 点ぶん持つので、差は 683 分の1(21.0MB と 31.5KB)。

2. 射影は「その基底とどれだけ似ているか」を足すだけ — ただし立体角で重みを付ける

キューブマップの各テクセルは、ある向きから来る光の明るさ。これを SH の係数にするのが射影:

  L_i = Σ(テクセル)  明るさ x Y_i(向き) x 立体角

立体角を忘れると壊れる。面の真ん中のテクセルは正面から見ているので大きく、隅のテクセルは斜めから見ているので小さい。32x32 の面では真ん中と隅で 4.86 倍違う。等しい重みで足すと隅(立方体の角の向き)を5倍近く重く数え、面の境目の向きから来る光を大きく見積もる。

立体角の求め方6面ぶん足すと使うところ
厳密な式(atan2(xy, √(x²+y²+1)) を4隅で足し引き)ちょうど 4π(12.56637)今日(SphericalHarmonics.TexelSolidAngle)
近似 4 / (n² (1+u²+v²)^1.5)4π に近い広く使われている

射影が済んだら、次数ごとに 1 / 2/3 / 1/4 を掛ける(ToIrradiance)。Day 36 では画素ごとに半球を刻んで積分していた (0.025 ラジアン刻みで、1テクセルあたり 1 万 6 千回ほど読む)ところが、9回の掛け算になる。これが SH で持ついちばんの御利益。

向きの表(どのテクセルがどの向きか)は OpenGL の仕様の表(Table 8.19)をそのまま写す。Day 36 の Program.CubeTexelDirection と同じもので、覚えるものではない。撮るときの6面のカメラ(IrradianceProbes.Faces)も Day 36 の CubeMap.FaceViews と同じ表で、この2つが食い違うと、その面の光が別の向きから来たことになる——自己チェックが「空だけを撮ったプローブ」で突き合わせる(6面とも 1.00)。

3. 焼くのは「その場所から見えたもの全部」。変えるのは4つだけ

撮るのは本描画と同じ textured.frag で、違うのはカメラ(90 度・1:1)と、PrepareProbeCapture が変える4つの uniform だけ。

変えるものなぜ
SSAO を切る遮蔽率のテクスチャは本描画のカメラで作った画面のもの。撮るカメラとは画素が対応しない
定数の環境光を 0撮った光に、手で決めた光が混ざらないように

プローブ1回目は使わない(環境光なし)。2回目からは前の回のもの(要点6)

光の渡し方はフォワード(uniform の配列)。Forward+ の升目は本描画のカメラで切ったもので、撮るカメラの画面とは合わない。

焼かないものが2つある。

1つ目は光る材質(窓の板・街灯のガラス・看板)。Day 56 で、灯りは「照らす側(点光源)」と「見える側(光る材質)」の2つでできていると書いた。窓の照らす側は板の 40cm 手前からもう壁と路面を照らしているので、板まで焼き込むと同じ窓の光を、点光源として1回、板の照り返しとしてもう1回数えることになる。F6 で焼くと、平均の明るさが 0.0336 → 0.0417(+24%)になる。

2つ目は揺らぎ。灯りは揺らぎの無い満点で焼く。焼くのは一度きりなので、押した瞬間の揺らぎを焼き込むと、押すたびに明るさが変わる。代わりに、ランタンが揺らいでも照り返しは付いてこない(要点7)。

空は撮る。壁の切れ目から見える空も「その場所から見えたもの」の一部で、夜は 7% の明るさで写る。つまりプローブは、IBL の拡散(空)を丸ごと置き換える。空が壁に隠れている場所では、空からの光も減る。

4. SH が苦手なもの — 小さく明るい光(と、それを 32x32 で撮ること)

9個では小さな光を小さく持てない。真上の半径 10 度の円だけが光る空を射影すると、

本当の値9個で持つと
上向きの面0.03020.0307
下向きの面00.0017(上の 5.6%)

ぼやけて広がり、真裏にまで漏れる。灯りを点光源のまま当てているのはこのためで、灯りの直接の光を SH に入れると、灯りの真裏の面まで光ってしまう。プローブが運ぶのは、灯りに照らされた面からの光(広がりのある光)だけにしてある。

重みは距離だけで決まる。壁の向こうの点も、近ければ同じだけ効く。格子は左の壁(x = −4)の外に1列(x = −5)はみ出させてあり、壁から 50cm 外の地面は、8点の重みの 33% を壁の内側のプローブから受け取る。

漏れの量は格子の粗さでは決まらない。3.0m のほうが 1.5m より漏れが少ないのは、壁をまたぐ升の中で壁が内側の列から遠く(重み 17%)、しかも内側の列(x = −2)が街灯から離れていて照り返しを多く見ていないから。壁をまたぐ升のどこに壁があるかと、内側の列が何を見ているかの2つで決まる。間隔を細かくすれば升は小さくなるが、列の置き場所を選ばない限り、漏れる升は必ずどこかに残る。

格子の外は、端のプローブで塗る(位置を格子の中へ寄せる)。壁からずっと離れた地面は x = −5 の列の値になる。もう1つ、片面の壁は裏から透けて見える。壁は1枚の板で、裏面は間引いて描いているので、壁の外のプローブからは壁の向こうの通りが見えている。Day 66b で読む DDGI は、この2つ(重みが壁を知らない・点が壁の中や裏に居る)を「その点から、ここが見えるか」(深度)と「点が裏面ばかり見ていたら使わない」で防ぐ。

3D テクスチャの補間に任せない理由は2つ。1つはサンプラの数——27 個の数を RGBA の 3D テクスチャに入れると7枚要り、textured.frag はすでに 14 枚使っている。もう1つが上の話で、8点の重みがシェーダの中で見えていれば、「この点は壁の向こうだから 0 にする」を後から足せる(改造課題2)。係数は横 9 列・縦 448 行の2D テクスチャに入れ、texelFetch で1つずつ読む。

6. 跳ね返りを重ねる — 同じ関数を、前の回の結果で照らして呼ぶ

1回目は環境光なしで撮る。写るのは直接照らされた面なので、縮めたものは「1回跳ねた光」。2回目は1回目の係数で照らして撮る。照り返しに照らされた面が写るので、跳ねる回数が1つ増える。

跳ね返り全プローブの平均の明るさ増えた量

増え方が急に減るのは、面が光の一部しか返さないから(路面やレンガのアルベドは 0.2〜0.4)。1回跳ねるたびに数分の1になるので、足し算がすぐ収まる。既定を2回にしたのはこのため(3回目は焼く時間が 1.3 倍になるのに、平均は 0.0001 しか増えない)。

差し替えるのは全部撮り終えてから(IrradianceProbes.Bake)。途中で差し替えると、先に焼いたプローブの光を後のプローブが拾い、並べた順で明るさが変わる(格子の片側だけ1回多く跳ねる)。

8. 絵の差が小さい理由と、値段

最終の絵でプローブを入れると、暗いところが 中央値で +2.2%、上位 1% で +10%、上位 0.1% で +17% 明るくなる。成分表示(放射照度)では一目で分かるのに、最終の絵で控えめなのは、このシーンに暗がりがほとんど無いから。

  • 灯り(点光源)は影を持たない(Day 52)。届く距離の中なら、壁の裏でも物の陰でも直接の光が当たる
  • 照り返しは直接の光の数分の1(アルベド x 見えている面積)。直接の光が当たっている面では、足しても目立たない
  • 照り返しが主役になるのは、直接の光が届かないところ——いちばん効いているのは突き当りの壁の右側とバリアの裏

プローブの値打ちは色にも出る。灯りのまわりは暖色、看板の前は桃色に染まる(空だけなら、どこも同じ青)。Day 56 の課題3(街灯に影を付ける)をやると、影の中は照り返しだけになり、今日の差がはっきり出るはず。
